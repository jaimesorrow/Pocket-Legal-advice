# Pocket Lawbook

Know your rights, with sources you can check.

Pocket Lawbook helps people understand what legal rights may be implicated in a
situation they describe, and points them to vetted, cited source material.

**Pocket Lawbook provides legal information, not legal advice.** It does not
create an attorney-client relationship and is not a substitute for consulting a
licensed attorney in your jurisdiction.

## Design principle: verified text only

The app's defining architectural rule is that no free text generated by a remote
or LLM API is shown to the user as legal content. A remote model may identify
*which* rights or violations apply, as stable keys; every human-readable string
the user sees is looked up from a local, vetted database keyed off that
identifier. See `CLAUDE.md` for the full pipeline and the invariants enforced by
`LegalAnalysisViewModelTest`.

## Build

Requires an Android SDK (platform 35, build-tools 35.0.0) and JDK 17+. Point the
build at your SDK via `local.properties`:

```
sdk.dir=/path/to/android-sdk
```

Then:

```
./gradlew test            # JVM unit tests
./gradlew assembleDebug   # debug APK
./gradlew lint            # Android Lint
```
